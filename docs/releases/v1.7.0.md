## cost-report 1.7.0

第七輪實機 review 後的修正（該輪結論已是「可以上線、沒有阻擋項」，以下是建議一併處理的項目）。

**後端**
- 期間起點早於 OpenCost 最早的資料時，從資料起點開始查：OpenCost 會依區間長度換取樣精度，原本「24h」和「指定那天」查同一段資料，最後一位數會不同。覆蓋率仍以要求的完整期間計算。
- 抓取覆蓋率不計入資料範圍邊緣的缺口。
- `config.dataSince` 只在資料起點落在最長的區間內時提供。

**頁面**
- 日期欄離開時就套用合法的日期；不合法時欄位還原，並留著提示直到修正。
- 「期間開頭或結尾沒有資料」的分鐘數不再重複計入邊緣缺口。
- 效率長條：超過申請量（橘色）與幾乎沒在用（灰藍色）分開顯示，並加上圖例。
- 指定的日子還沒結束時，頁首顯示「目前算到 HH:MM」。
