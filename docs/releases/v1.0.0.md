## cost-report 1.0.0

以 Rust 重寫，並整合成 Rancher UI extension。Python 版保留在 `demo` 分支。

- 後端改成 Kubernetes aggregated API：經 Rancher 代理以使用者自己的身分呼叫，部門的可見範圍由 RBAC 決定（`get departments/<代號>`）。
- Rancher UI extension「成本分攤」：部門成本與帳期兩頁，繁體中文與英文。
- Helm chart：後端、宣告量快照器、PVC 用量量測（選配）、使用者 ClusterRole、每個部門一個 ClusterRole。
- 部門名稱、環境、系統 namespace、出帳門檻都改成設定，不再寫死。
- 封存的雜湊改用 Rust 的 JSON 序列化計算，與 Python 版的封存檔不相容（Python 版的封存請留在原環境）。
