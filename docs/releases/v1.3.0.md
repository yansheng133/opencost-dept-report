## cost-report 1.3.0

第三輪實機 review 後的修正。

**後端**
- 「1h／24h／7d」改成「到現在為止的最近 N 小時」：後端自己換算成絕對區間再問 OpenCost。OpenCost 的相對區間會對齊整點、包含這個整點還沒發生的部分，那段未來時間原本被算成「沒量到」，讓「1h」永遠過不了覆蓋率檢查。
- 指定的日子還沒結束時只算到現在，所以今天不會再把還沒到的時間算成缺漏；還沒開始的日子回 400。
- 回應多了實際查詢的區間（`window.requested`），設定多了最早資料時間（`dataSince`）。

**頁面**
- 全頁金額統一一種小數位數（依本期總額決定），篩選部門不會改變；不為 0 但太小的金額顯示「<0.01」。
- 快速連結可以打開已收合的區段；目前區段的標示改用固定列下方 40 px 的基準線，捲到底時標示最後一個區段。
- 日期欄只在按 Enter、離開欄位，或停止輸入 1.2 秒後才查詢。
- 頁首顯示實際查詢的區間與資料起點；載入中有佔位畫面。
- 工作負載的說明不再與該列資料矛盾；極小的用量顯示「<1 MiB」「<0.001」。
- 對帳說明把資產成本的組成放在它加總的那個數字旁邊。
- 帳期頁依最早資料時間算出第一筆封存的預計時間。
