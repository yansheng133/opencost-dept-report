## cost-report 1.1.0

頁面配置依實際操作的 review 調整，並修正三個會讓人看錯帳的問題。

**修正**
- 覆蓋率橫幅原本只算中間的斷層，期間開頭沒有資料的時間沒算進去（覆蓋率 8% 卻寫「缺 1 分鐘」）。現在兩者分開寫。
- 閒置成本「按比例分攤」時，部門表各欄加總不等於小計。新增「分攤閒置」一欄，計算式也一併補上。
- 選到沒有資料的期間時，推估佔比、無法分攤佔比、覆蓋率會顯示「通過」。現在一律顯示「未知」，頁面只留一張說明卡。另外，有價目表但期間沒有適用版本時，會明講（`rates_no_version`），不再說「沒有價目表」。

**配置**
- 總額卡片移到最上方；出帳關卡可以收合，收合時仍顯示一行摘要。
- 篩選某個部門時，全叢集的區段加上「全叢集」標記，頁首也說明篩選範圍。
- 區段快速連結跟著捲動，並標出目前所在的區段；區段收合時標題旁顯示重點數字。
- 金額依大小決定小數位數、加千分位，並標示幣別；數字欄的表頭與數值對齊；使用率超過 100% 改用警示色。
- 「無法分攤」加上「其他 N 個 namespace」，百分比加總為 100%；部門長條與閒置、無法分攤各用各的比例尺。
- 使用率趨勢只保留線尾標籤，並避免標籤重疊。
- 切換期間時，舊的內容會變暗並顯示載入中。指定某一天時，頁首顯示那一天（UTC），不再顯示自動更新。

**後端**
- 封存程序啟動後先等兩分鐘，每封一天之間間隔 20 秒。原本一啟動就連查 7 天，會把 OpenCost 連往 Prometheus 的連線用完，同一時間使用者的查詢也跟著失敗。
- 指定某一天時，如果 OpenCost 查詢失敗，錯誤代號改成 `upstream`（502），不再誤報成 `not_ready`。
