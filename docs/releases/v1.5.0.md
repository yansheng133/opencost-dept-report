## cost-report 1.5.0

第五輪實機 review 後的修正。

**後端**
- 使用率序列的每一段多了 `partial`：涵蓋不到取樣間隔 90% 的段（資料開頭、斷層後第一段、還沒結束的最後一段）平均值會偏低，頁面畫成虛線並說明。
- 監控目標的狀態分成 `degraded`（有目標回報 down）與 `changed`（目標數量有變動），不再把目標數變動說成「曾經掉線」。
- 覆蓋率的缺口標記是否在資料範圍的邊緣（`edge`、`edgeGapMinutes`）：資料開始的第一分鐘不再算成「中間斷了」。
- 自選取樣間隔時 OpenCost 沒有回傳分段資料，錯誤代號改成 `no_segments`，不再說「可能正忙，稍後再試」。

**頁面**
- 鍵盤輸入日期不再被每秒重繪清掉：更新時間改由獨立的小元件跳秒，日期欄在輸入時保留草稿。
- 分攤模式的部門表不再超出外框；固定表頭不再半透明。
- 更新頻率的說明照實寫出資料最多可能是幾分鐘前。
- 日期錯誤提示不再讓工具列跳動；目前區段的判斷線改在可視範圍三分之一處。
- 核數、MiB 在說明文字與表格中格式一致。
