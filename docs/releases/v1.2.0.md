## cost-report 1.2.0

第二輪實機 review 後的修正（只改頁面，後端行為不變）。

**會讓人看錯帳的**
- 閒置成本「按比例分攤」時，「無法分攤」的金額在卡片、區塊、出帳關卡三處不一致：區塊與出帳關卡標明是獨立列帳基準，分攤模式另外列出兩種數字。
- 「計價依據」的用量是各部門的合計，不是全叢集：欄名改成「各部門合計用量」，篩選部門時改顯示該部門的用量與金額。
- 選今天（UTC）時不再寫「過去的日子」，改說明尚未結束、數字還會變動，並繼續自動更新。
- 換日期載入時，變暗的舊內容仍描述已載入的那段期間，不會提前顯示新日期的「沒有資料」。
- 日期欄只有輸入完整、合法的日期才查詢，不會每打一段就送出。

**配置**
- 同一欄、同一組金額使用相同的小數位數；表頭與數值精確對齊。
- 快速連結會換行，「全部收合／全部展開」移到控制列；目前區段的標示在頁首與重新載入後都正確。
- 長表格的表頭跟著捲動；名稱欄加寬並可換兩行；0 元不畫長條。
- 指定某一天時同時顯示 UTC 日與瀏覽器時區的起訖時間。
- 收合摘要改成重點數字（各部門平均使用率、各環境金額、最貴的工作負載）。
- 帳期頁的空白狀態寫明第一筆封存何時產生。
